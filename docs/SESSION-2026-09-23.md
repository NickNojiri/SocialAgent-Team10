## Block 2 — Clone + install (0:25–1:05)

**Mac:**
```bash
xcode-select --install
brew install python@3.12 gh
git clone https://github.com/NickNojiri/SocialAgent-Team10.git
cd SocialAgent-Team10
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
ollama pull mxbai-embed-large
```

**Windows (PowerShell):**
```powershell
winget install --id Git.Git
winget install --id Python.Python.3.12
winget install --id GitHub.cli
git clone https://github.com/NickNojiri/SocialAgent-Team10.git
cd SocialAgent-Team10
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

Install Ollama from https://ollama.com/download and open it once, either way.
Close and reopen the terminal after installing, so the new commands are found.

Then log GitHub in so you can push later:
```bash
gh auth login
```
(GitHub.com → HTTPS → log in with a web browser.)

## Checkpoint 1 — the tests (1:05–1:20)

**Mac:**
```bash
.venv/bin/python -m pytest -k "not live" -q
```
**Windows:**
```powershell
.\.venv\Scripts\python.exe -m pytest -k "not live" -q
```

You want **`291 passed`**. Nobody moves on until their own machine prints that — say the
number out loud, one at a time. If yours says fewer, you're on an old clone: `git pull`.

Common stalls: `running scripts is disabled` on Windows → use the
`powershell -ExecutionPolicy Bypass -File …` form. SSL/certificate errors → you're on
campus Wi-Fi. Playwright fails → rerun just the `playwright install chromium` line.
