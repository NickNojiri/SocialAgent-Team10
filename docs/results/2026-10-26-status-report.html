What changed today

  • The "Not a place" list can no longer lose a spot. A moved spot is the only copy left, so it is now saved under its own id, kept past the 30-day expiry and the 300-item cap, and only removed after "Move it back" succeeds.
  • Bot cards behave under load. Buttons answer inside Discord's 3-second limit, wait past the model's 90-second timeout, and failed links next to not-a-place cards get Retry / Add manually.
  • The Instagram webhook never returns a 500. Any delivery shape is skipped safely (Meta resends every non-200), and every sender id is hashed in the event log.
  • Sprint board gets an archive command. It writes one index post that links every Phase 2 standup, digest and finished feature, then closes those posts. Nothing is deleted.
