SpotBot evaluation report

October 27, 2026 · How well does SpotBot figure out which place a reel is about? · Written for the whole team. Terms are explained at the end.

Short answer: our trained model gets the right place for about 3 in 4 reels (74%), against 62% for the hand-written rules SpotBot uses today. That's 33 more reels right out of 271, and the gain is far too big to be luck. We recommend making it the default.

Which approach works best

Right place, out of the same 271 dev reels. Dashed line: today's rule parser. Rows with several training runs show their average.

What M2 is: a small AI model we trained ourselves. For each reel it looks at every name the reel offers (the location tag, @mentions, the caption, speech, text on screen) and picks the one most likely to be the place, or "no place".

Training is what makes it work. The same model before we trained it gets only 30.6%.

v6 is 2 reels better than the ★ model, but it needs an LLM's guess as an input, which takes about 15 s per reel. That 2-reel gap is within noise. The ★ model gets nearly the same result in about 0.3 s, with no LLM.

An LLM alone does worse than our model (66.8%), and it's the slowest option.

The p-value is the chance of a gain this large if the model were really no better. Under 0.05 counts as real. The original 106 alone are too few to be sure, which is why the dev set was enlarged.

Yes. On the full dev set the model fixes 38 reels the rules got wrong and breaks only 5 the rules got right. The likely range of the gain is +7.7 to +16.6 points.

The gain also holds on the reels a person labeled, so it isn't an artifact of machine-made labels.

When a near-miss counts ("Casa Loma" vs "Casa Loma Tacos"), the model gets 220 of 271 (81%), against 194 for the rules.

Recipes, memes and ads should get a "not a place" card instead of a spot. The bigger LLM catches twice as many, but it also throws out 5 real spots. Losing a real spot is worse than letting a meme through, so this part isn't solved yet. We need more not-a-place examples to train on.

Fair-test rules we kept: every number here is on the dev set. The test set (204 reels nobody has looked at) is saved for one final measurement after we pick the model, so the number we report isn't one we tuned toward. Reels are split by creator, so no account appears in both training and dev. One honest caveat: the ★ setting was picked from 3 tries on dev, so one more training run should confirm it before the test read.

Recommendation and next steps

  • Make M2 v5 (trained 5 rounds) the venue picker, with the rule parser as a fallback when the model isn't confident. It's fast enough to run on every paste.
  • Confirm it: run one more training with a different seed. If it lands within 2–3 reels, freeze it and read the test set once.
  • Retrain with full speech (finished this morning: 626 reels, 330 with speech), and keep labeling: accuracy was still climbing with the last batch of labels.
